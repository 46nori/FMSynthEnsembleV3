# SMF Track Counter (count_smf_tracks.py)

大量のMIDIファイルから、フォーマット種別（0/1/2）とトラック数を再帰的に集計するコマンドラインツールです。SmfPlayerTaskがトラックごとに保持するFatFsハンドル数の上限（`FF_FS_LOCK`）を何件に設定すべきか、手持ちのMIDIファイル群から実測して検討するために作成しました（[doc/design_smf_player.md](../../doc/design_smf_player.md) 参照）。

## 主な機能

- **再帰的スキャン**: 指定したディレクトリ配下の子フォルダもすべて自動で検索します。
- **トラック数の一覧・分布表示**: 全ファイルをトラック数の多い順に一覧表示したうえで、トラック数ごとの件数分布（ヒストグラム）を表示します。
- **しきい値超過ファイルの抽出**: スクリプト冒頭の `THRESHOLD` を超えるトラック数のファイルを末尾にまとめて表示します。

## 前提条件

- Python 3.10 以上
- `mido` ライブラリ

## 導入手順

### 1. 依存ライブラリのインストール

仮想環境（`venv`）を有効にした状態で、以下のコマンドを実行します。

```bash
pip install mido
```

## 使い方

スクリプトを実行する際、引数に対象のMIDIファイルが格納されているディレクトリのパスを指定します。

```bash
python3 ./count_smf_tracks.py '/path/to/your/midi/folder'
```

引数を指定せずに実行した場合は、画面上でパスの入力を求められます。

```bash
python3 ./count_smf_tracks.py
スキャンするディレクトリのパスを入力してください:
```

### 出力例

```text
Tracks  Fmt  ファイル
    18    1  /path/to/midi/Song_A.mid
    17    1  /path/to/midi/Song_B.mid
     1    0  /path/to/midi/Song_C.mid

トラック数の分布:
    1 トラック:    3 件
   17 トラック:   12 件
   18 トラック:    1 件 *

走査ファイル数: 16
最大トラック数: 18
トラック数が17を超えるファイル: 1件（上の分布表で * を付けた行）
   18  /path/to/midi/Song_A.mid
```

## しきい値の変更

集計対象のしきい値は、スクリプト冒頭の `THRESHOLD` を書き換えることで変更できます。

```python
THRESHOLD = 17
```

## 既知の制約

- トラック数のみを集計し、各トラックの内容（チャンネル数・イベント数など）は見ません。
- 読み込みに失敗したファイル（破損ファイル・非MIDIファイル等）は標準エラー出力にパスとエラー内容を出力し、集計からは除外します。
