# MIDI Message Finder (find_midi_msg.py)

大量のMIDIファイルから、特定のMIDIメッセージ（コントロールチェンジ、ノート、SysEx、メタイベントなど）や、それらが複数並ぶ「シーケンス（連続パターン）」が含まれるファイルを再帰的に検索し、そのファイルパスを一覧表示する汎用コマンドラインツールです。

## 主な機能

- **再帰的スキャン**: 指定したディレクトリ配下の子フォルダもすべて自動で検索します。
- **全MIDIメッセージに対応**: CCやノートだけでなく、SysEx（システムエクスクルーシブ）やメタイベント（テキスト等）も区別なくスキャン対象に含めることができます。
- **シーケンス（連続メッセージ）の検出**: 複数メッセージにまたがる「流れ」（例：NRPN 1:10）をMIDIチャンネルごとに独立して追跡・検知します。全トラックを絶対時間順にマージしてから走査するため、対象シーケンスの各メッセージが別トラックに分かれて記録されている場合（Format 1 の MIDI ファイルで起こり得ます）も検出できます。
- **高速処理**: 条件に一致した時点で該当ファイルのスキャンを切り上げるため、大量のファイルも高速に処理できます。
- **シンプルな出力**: 一致したファイルのフルパスのみを標準出力するため、他のコマンド（`grep` やシェルスクリプトなど）と柔軟に連携可能です。

## 前提条件

- Python 3.10 以上
- `mido` ライブラリ

## 導入手順

### 1. 依存ライブラリのインストール

仮想環境（`venv`）を有効にした状態で、以下のコマンドを実行します。

```bash
pip install mido
```

## 使い方

スクリプトを実行する際、引数に対象のMIDIファイルが格納されているディレクトリのパスを指定します。

```bash
python3 ./find_midi_msg.py '/path/to/your/midi/folder'
```

引数を指定せずに実行した場合は、画面上でパスの入力を求められます。

```bash
python3 ./find_midi_msg.py
スキャンするディレクトリのパスを入力してください:
```

### 出力例

条件に合致したMIDIファイルのフルパスが1行ずつ出力されます。

```text
/Users/username/Documents/MIDI/Song1.mid
/Users/username/Documents/MIDI/Techno/Pattern_A.mid
```

## 検出条件（ターゲットシーケンス）の変更

検索したいメッセージのパターンは、スクリプト冒頭の `TARGET_SEQUENCE`（辞書のリスト形式）を書き換えることで自由に変更できます。

### 設定例

#### 1. NRPN 1:10 を検出する場合（デフォルト）
CC#99（値:1）の直後にCC#98（値:10）が送信されるパターンを検出します。
```python
TARGET_SEQUENCE = [
    {"type": "control_change", "control": 99, "value": 1},  # NRPN MSB = 1
    {"type": "control_change", "control": 98, "value": 10} # NRPN LSB = 10
]
```

#### 2. 特定の SysEx（システムエクスクルーシブ）を検出する場合
`mido` の内部仕様上、SysExの `data` プロパティはタプルで保持されるため、設定側も必ず **`( )`（丸括弧）** で記述してください。
```python
TARGET_SEQUENCE = [
    # 例：Rolandの特定のSysEx（データバイトの配列を指定）
    {"type": "sysex", "data": (0x41, 0x10, 0x42, 0x12, 0x40, 0x00, 0x7F, 0x00, 0x41)}
]
```

#### 3. バンクセレクトの後にプログラムチェンジが来るパターン
値（value）を省略すると、「任意の数値」としてワイルドカード扱いになります。
```python
TARGET_SEQUENCE = [
    {"type": "control_change", "control": 0},   # バンクセレクト MSB
    {"type": "control_change", "control": 32},  # バンクセレクト LSB
    {"type": "program_change"}                 # 音色切り替え
]
```

#### 4. 特定の「音（ノート）」の連続を検出する場合
「ド(60)・ミ(64)・ソ(67)」という順番でノートオンが並んでいるファイルを探します。
```python
TARGET_SEQUENCE = [
    {"type": "note_on", "note": 60},
    {"type": "note_on", "note": 64},
    {"type": "note_on", "note": 67}
]
```

## 既知の制約

- `TARGET_SEQUENCE` 内で同じメッセージ条件（`type` とその他プロパティの組み合わせ）が複数回登場する場合、判定ロジックが単純な逐次比較のため、一部の組み合わせで検出漏れが発生する可能性があります（例: `[A, B, A, C]` のように途中の要素が自己反復するパターンで、`B` の直後の `A` を取りこぼすケース）。`TARGET_SEQUENCE` 内の各要素が重複しない通常の用途では問題ありません。
